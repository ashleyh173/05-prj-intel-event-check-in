# 🌱 Intel Sustainability Summit Check-In

An interactive event check-in web application designed for managing attendance at an Intel Sustainability Summit. The application allows attendees to enter their name, select a sustainability team, and check in while displaying real-time attendance progress.

## 🎮 Try the Project

[**Launch Intel Sustainability Summit Check-In**](https://ashleyh173.github.io/Intel-Event-Check-In/)

## 📖 About the Project

The **Intel Sustainability Summit Check-In** is a browser-based event management tool created to provide a simple and engaging way to track event attendance.

Attendees can enter their name, select one of three sustainability-focused teams, and check in to the event. The interface provides an overall attendance count and individual team attendance totals.

The event has a maximum capacity of **50 attendees**.

## ✨ Features

* 👤 **Attendee Check-In** — Allows users to enter their name and check into the event.
* 👥 **Team Selection** — Attendees can choose between three sustainability teams.
* 📊 **Live Attendance Tracking** — Displays the current number of attendees out of 50.
* 🌊 **Team Water Wise** — Tracks attendance for the Water Wise team.
* 🌿 **Team Net Zero** — Tracks attendance for the Net Zero team.
* ⚡ **Team Renewables** — Tracks attendance for the Renewables team.
* 📈 **Progress Indicator** — Visualizes event attendance progress.
* 💬 **Personalized Check-In** — Provides feedback when an attendee successfully checks in.
* 📱 **Responsive Design** — Designed to work across different screen sizes.

## 📊 Attendance System

The application is designed for a maximum of **50 attendees**.

The dashboard displays:

```text
Attendance: 0/50
```

As attendees check in, the attendance count and progress indicator update to reflect the current event capacity.

Each team also maintains its own attendance count, allowing event organizers to see how attendees are distributed across the three sustainability teams.

## 🧠 How It Works

1. Enter your name in the check-in field.
2. Select a sustainability team.
3. Click **Check In**.
4. The attendee is added to the event attendance count.
5. The selected team's attendance count is updated.
6. The overall attendance progress is updated.
7. The attendee receives confirmation of their check-in.
